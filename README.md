# MSA-3-NovaMarket

Проектная работа 3 спринта курса «Микросервисная архитектура»: архитектура маркетплейса NovaMarket.

| Задание | Что сдаётся | Где |
| :- | :- | :- |
| 1. Приложение на базе EDA | C2-диаграмма, реестр событий Saga оформления заказа, sequence-диаграммы успешного и ошибочных сценариев | [Task1](Task1/README.md) |
| 2. Агрегированные данные на фронтенде | Обновлённая C2-диаграмма, ADR (CQRS для истории покупок) | [Task2](Task2/ADR.md) |
| 3. Масштабирование под нагрузку | Манифесты Deployment, Service, HPA; логи изменения числа реплик под нагрузкой | [Task3](Task3/README.md) |
| 4. Надёжность | Конфиги NGINX: rate limiter по каналам и circuit breaker к логистике, с проверками | [Task4](Task4/README.md) |

Диаграммы сделаны в PlantUML (C4-PlantUML). Рядом с каждым `.puml` лежит отрисованный `.png`.
